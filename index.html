Sources

Activity
GitHub Innovation Graph. Public git pushes and developer accounts per quarter. GitHub assigns a country from each account's most common IP location, so remote work and VPNs can move activity between countries.
Growth
Change from the chosen baseline quarter to the latest complete quarter. Ranks use the selected measure in that quarter.
Colour
A fixed signed-log transformation keeps both declines and unusually large increases visible. Values above +1,200% share the final colour. Hatched countries lack a comparable baseline. Exact changes appear in the country card.
Selected measure
Coverage
Population
World Bank annual population is used only when the scale is set to per 1M people. Population-normalized comparisons stop at 2025 Q4; the 2026 Q1 GitHub release remains available in the total view.
Values
Country-quarter data (CSV). GitHub data: CC0. Population: World Bank, CC BY 4.0. Source details.
India boundary
Survey of India political map, digitised by the DataMeet community (CC BY 4.0). Neighbouring countries are clipped to it.
Country underlay
Natural Earth 1:110m sovereign boundaries, public domain. It distinguishes countries outside the GitHub data universe from open water.
Basemap
OpenFreeMap tiles built with OpenMapTiles from © OpenStreetMap contributors. Its own borders are hidden.
