Country
GitHub places an account in the country linked to the IP address it used most often that quarter. Remote work and VPNs can affect the country shown.
Growth
(current ÷ baseline − 1) × 100The map shows growth only when both quarters have published values and the baseline is above zero.
Per 1M people
reported value ÷ same-year population × 1,000,000The reported value is divided by that year's World Bank population. Population data ends in 2025, so this view stops at 2025 Q4.
Global share
country value ÷ published global total × 100Each country is compared with the total of all published country values. The EU total is left out so member countries are not counted twice.
Rank
A country ranks behind every country with a higher published value. Countries with the same value get the same rank.
Colour
sign(growth) × ln(1 + |growth| ÷ 50)This scale squeezes very large changes so smaller rises and falls stay visible. The colours stop changing below −100% and above +1,200%.
Country bars
The change farther from zero fills the bar. The other bar is sized against it. The labels show the actual percentage changes.
Missing data
Hatching means that either the current value or the selected baseline is missing or cannot be used. A missing value never counts as zero.
